Secrets Vault

Your .env files, safe in a private repo. For free.

Secrets are ignored by Git, so they are the first thing you lose when you delete a project or change Macs. The Vault fixes that.

  • Encrypted before it leavesAES-256-GCM on your Mac. GitHub only ever stores ciphertext.
  • Your key, your KeychainPlus a recovery key you keep in your password manager.
  • Smart syncSee what changed locally, what is newer in the vault, and restore with one click.

Get started

Install in a minute.

Download the app

Grab the latest .dmg, drag it to Applications. The app is not notarized yet, so remove the quarantine flag on first launch:

xattr -dr com.apple.quarantine \
  "/Applications/Git Manager.app"

Build from source

Requires macOS 14+ and Xcode 16+.

git clone https://github.com/guibais/git-manager.git
cd git-manager
./scripts/build-app.sh
